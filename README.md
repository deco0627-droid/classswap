# 수업시간 교체 도우미 (ClassSwap)

출장 등의 사유로 수업시간을 다른 교사와 교체해야 할 때, 조건(제외 교사·전문교과 그룹·기간)에 맞는 교체 상대를 자동으로 추천하고, 여러 건을 한꺼번에 처리해도 같은 교시가 중복으로 배정되는 충돌을 막아주는 도구입니다.

- 설치/빌드 없이 **`index.html` 파일 하나만** 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.
- 모든 데이터는 그 브라우저의 **로컬 저장소(localStorage)**에만 저장됩니다. 서버나 외부 전송 없음.
- 브라우저 캐시 삭제 시 데이터가 날아갈 수 있으니, 상단의 **"백업 내보내기(JSON)"**로 주기적으로 파일을 저장해두세요. 다른 PC/브라우저로 옮길 때도 이 JSON 파일로 "백업 가져오기"를 쓰면 됩니다.

## 사용 순서

### 1. 교사 관리
- "+ 새 교사"로 추가하거나, 2단계(시간표 가져오기)에서 이름이 자동으로 등록됩니다.
- 각 교사를 펼쳐서 과목, **전문교과 여부**(+ 세부 그룹), 그리고 **"이 교사와는 교체하지 않음"** 목록을 설정하세요.
  - 전문교과로 표시한 교사는, 그 교사의 수업을 대신할 후보를 찾을 때 **전문교과로 표시된 다른 교사끼리만** 서로 후보가 됩니다(세부 그룹까지 입력하면 같은 그룹끼리만).
  - 일반(보통교과) 교사는 이런 제한 없이, 제외 목록에 없는 모든 교사가 후보가 됩니다.

### 2. 시간표 가져오기/편집
- 엑셀에서 교사별 시간표 범위를 복사(Ctrl+C) → 붙여넣기 칸에 Ctrl+V → "붙여넣은 내용으로 미리보기", 또는 .xlsx/.csv 파일을 바로 업로드하세요.
- 첫 행(머리글)에서 "월1", "화3" 같은 표기를 자동으로 요일·교시로 인식합니다. 인식이 안 된 열은 표에서 직접 요일/교시를 지정하거나 "사용 안 함"으로 제외하세요.
- 미리보기 확인 후 "시간표 가져오기"를 누르면 이름이 같은 교사는 해당 교시만 새 내용으로 덮어쓰고, 새 이름은 교사로 자동 추가됩니다.
- 하단 "시간표 직접 보기/수정"에서 교사를 선택해 칸을 클릭하면 개별 교시를 수동으로 고칠 수 있습니다(가져오기가 잘못됐을 때의 보정용).

### 3. 출장·교체 계획
- 출장 가는 교사, 기간(시작~종료일), 사유를 입력하고 필요하면 이번 건에만 추가로 제외할 교사를 체크한 뒤 "출장 등록"하세요.
- 등록되면 그 기간에 해당하는 모든 수업 교시가 자동으로 나열되고, 각 교시마다:
  - **맞교체 가능** 후보: 그 교사도 비어 있고, 그 교사의 다른 수업 시간 중 출장 교사가 비어 있는 시간이 있어 **서로 자리를 바꿀 수 있는** 경우. 날짜가 가깝고 같은 요일일수록 위에 추천됩니다.
  - **단순 대체만 가능** 후보: 그 시간엔 비어 있지만, 맞바꿀 자기 수업 시간은 없는 경우.
  - 기본은 **설정한 기간 안에서만** 상대를 찾습니다. "기간 밖(±14일)에서도 찾기"를 체크하면 범위를 넓혀 참고용으로 더 찾아줍니다.
  - 추천이 마음에 안 들면 "직접 지정"으로 교사·시간을 수기 입력할 수 있습니다(제외 설정을 어겨도 확인 후 강제 지정 가능).
- 교시를 확정하면 그 시간은 **다른 모든 출장 건에서도 즉시 "이미 사용됨"**으로 반영되어, 여러 건을 동시에 처리하다가 같은 시간을 두 번 배정하는 충돌을 방지합니다.

### 4. 교체 내역
- 확정된 모든 교체를 날짜순으로 보고, 필요하면 "되돌리기"로 취소할 수 있습니다.
- "CSV로 내보내기"로 교무부 제출용 표를 바로 뽑을 수 있습니다.

## 참고
- 교시 수(하루 몇 교시)는 "교사 관리" 탭 상단에서 바꿀 수 있습니다. 기본 7교시.
- 토요일 수업은 v1에서 지원하지 않습니다(월~금만 계산).
- Firebase/로그인 없이 동작하는 1인 관리자용 도구입니다. 여러 교사가 각자 로그인해서 신청/승인하는 구조가 필요해지면 별도로 확장 가능합니다.
